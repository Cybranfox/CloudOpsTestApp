What you get

Everything you need to make learning stick

Cloud Orbit wraps real certification-level content in mechanics that keep you coming back.

🗺️

Adventure Map

Duolingo-style zigzag path. Each node is a battle — complete it to unlock the next. Green = done, gold = current, blue = available.

⚡

Energy Shields

Inspired by Slay the Spire's HP system. Wrong answer = lose a shield. Correct = gain one back. Resource management matters.

💎

Relics & Loot

Defeat elites and bosses to earn permanent passive bonuses — Guardian's Shield, CloudWatch Lens, Deployment Automation Gem.

📊

Progress Dashboard

Full stats panel: accuracy, battles won, elites slain, best streak, per-platform progress bars, relic shelf, achievement grid.

🔊

Sound Design

Procedural Web Audio synthesis — correct chimes, wrong buzz, shield crunch, level-up fanfare. No external audio files needed.

📱

PWA & Mobile

Installable as a PWA for offline use. Android APK build path via Capacitor. Works down to 375 px with no layout breakage.

Get running in 60 seconds

No database. No build step. Just Python.

Clone, install Flask, run. That's it.

# Clone the repo
git clone https://github.com/Cybranfox/CloudOpsTestApp.git
cd CloudOpsTestApp/AWS_Orbit_RPG

# Install the single dependency
pip install flask

# Launch
python app.py

# Open → http://localhost:5001
